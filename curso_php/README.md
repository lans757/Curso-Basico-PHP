# 🎓 Curso Completo de PHP: De Cero a Experto

Este repositorio contiene una colección estructurada de ejercicios y guías prácticas para aprender PHP, desde los fundamentos básicos hasta conceptos avanzados de desarrollo web y Programación Orientada a Objetos.

## 📂 Estructura del Curso

El proyecto está organizado en módulos temáticos para facilitar el aprendizaje progresivo:

### 1. 🧱 Fundamentos y Estructuras de Control

- **`/fundamentos`**: Sintaxis básica, variables y tipos de datos.
- **`/condicionales`**: Estructuras de decisión (`if`, `else`, `switch`).
- **`/ciclos`**: Bucles y repeticiones (`for`, `while`, `foreach`).
- **`/arreglos`**: Manejo de arrays indexados y asociativos.
- **`/funciones`**: Creación y uso de funciones reutilizables.
- **`/funciones_matematicas`**: Operaciones matemáticas nativas de PHP.

### 2. 🔌 Datos e Interactividad

- **`/formularios`**: Recepción y validación de datos enviados por el usuario (`GET` y `POST`).
- **`/cookies`**: Almacenamiento de información en el navegador del cliente.
- **`/sesiones`**: Manejo del estado del usuario en el servidor (Login/Logout).
- **`/conexion`**: Conexión a bases de datos y consultas SQL.
- **`/include_require`**: Modularización de código.

### 3. 🛠️ Herramientas de Depuración (Debugging)

Archivos sueltos en la raíz para ayudar en el diagnóstico de errores:

- `die.php`
- `var_dump.php`
- `print_r.php`

### 4. 🚀 Módulos Avanzados (Nuevas Incorporaciones)

#### 🔥 **`/objetos` y `/poo` (Programación Orientada a Objetos)**

- **Clases y Objetos**: Fundamentos de la POO.
- **Herencia**: Extensión de clases.
- **Clases Abstractas**: Plantillas estrictas.
- **Interfaces**: Contratos de implementación.
- **Traits**: Reutilización horizontal de código.
- **Namespaces**: Organización lógica y prevención de conflictos.

#### ⚠️ **`/errores`**

- Manejo profesional de excepciones con bloques `try-catch`.
- Creación de excepciones personalizadas (`extends Exception`).

#### 📁 **`/archivos`**

- Sistema de archivos: Crear, leer y escribir `.txt`.
- **Subida de archivos**: Formularios para cargar imágenes y documentos al servidor.

#### 🔒 **`/seguridad`**

- **Encriptación**: Hashing de contraseñas con `password_hash`.
- **Sanitización**: Prevención de ataques XSS con `htmlspecialchars`.

## 🌐 Visualización

El proyecto cuenta con una interfaz principal para navegar por los ejercicios:

- **`index.html`**: Página de inicio.
- **`style.css`**: Estilos generales del curso.
