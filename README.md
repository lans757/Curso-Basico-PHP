# 🐘 Curso de PHP: Fundamentos y Lógica

¡Bienvenido al repositorio del curso de PHP! Este proyecto está diseñado para sentar las bases sólidas en el desarrollo con PHP, enfocándose principalmente en la **lógica del lenguaje** y su potencia como herramienta de programación en el lado del servidor.

## 🎯 Objetivo del Curso

El objetivo principal es aprender las nociones básicas del empleo de PHP. A diferencia de otros cursos, aquí **no nos enfocamos en el HTML ni en el CSS**, sino en el uso de PHP como una herramienta lógica pura.

Queremos entender cómo procesar datos, manejar estructuras de control y construir funciones eficientes, dejando de lado la capa de presentación para concentrarnos en lo que ocurre "detrás de escena".

---

## 📚 Temas Cubiertos

El curso está organizado en módulos prácticos que cubren los pilares fundamentales:

- 📂 **Fundamentos:** Sintaxis básica y primeras instrucciones.
- 🔢 **Arreglos:** Manejo de datos estructurados, arreglos asociativos y multidimensionales.
- 🔁 **Ciclos:** Automatización de tareas con `for`, `while`, `do-while` y `foreach`.
- ⚖️ **Condicionales:** Toma de decisiones lógica en el código.
- 📝 **Formularios:** Procesamiento de datos enviados por el usuario (`GET` y `POST`).
- ⚙️ **Funciones:** Creación de bloques de código reutilizables y funciones nativas (matemáticas, texto, etc.).
- 🧩 **Include y Require:** Organización del código en múltiples archivos.
- 🛠️ **Herramientas de Depuración:** Uso de `var_dump`, `print_r` y manejo de errores con `die()`.

---

## 🚀 Cómo usar este repositorio

Para ejecutar estos ejemplos localmente, necesitarás un entorno de servidor local como **XAMPP**, **WAMP** o **Laragon**.

1.  Clona o descarga este repositorio dentro de tu carpeta `htdocs` (en XAMPP) o `www`.
2.  Asegúrate de que el módulo de Apache esté iniciado.
3.  Accede desde tu navegador a `http://localhost/nombre-de-tu-carpeta/`.
